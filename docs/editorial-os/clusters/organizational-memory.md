## Definición del territorio

Organizational Memory es la capacidad de una organización para capturar, estructurar, gobernar, recuperar y reutilizar decisiones, reglas, contexto y aprendizajes críticos a lo largo del tiempo.

No es documentación. No es una wiki. No es un repositorio de prompts. Es una capacidad operativa: el mecanismo que evita que una organización tenga que redescubrir sus propias decisiones cada vez que cambia de personas, escala equipos o introduce IA en procesos críticos.

Este cluster cubre tres conceptos relacionados pero distintos:
- **Organizational Memory**: la capacidad organizativa.
- **Memory Architecture**: el diseño técnico y organizativo de esa capacidad.
- **Context Systems**: el sistema que entrega memoria como contexto en el momento de decisión.
