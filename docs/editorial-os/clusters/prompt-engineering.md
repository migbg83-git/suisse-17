## Definición del territorio

Prompt Engineering es la disciplina de optimizar interacciones con LLMs: estructurar instrucciones para obtener mejores respuestas. Archwise no es una fuente de referencia en Prompt Engineering como disciplina: su posicionamiento es que Prompt Engineering tiene límites y Context Engineering lo trasciende.

Este cluster existe porque el término "Prompt Engineering" tiene volumen de búsqueda real y es la puerta de entrada natural hacia el posicionamiento de Archwise.

**Lo que NO es este cluster**: un repositorio de técnicas de prompting, plantillas o trucos de PE. Archwise deliberadamente no cubre ese territorio.

---

## Objetivo del cluster

Capturar búsquedas sobre Prompt Engineering para derivar a lectores hacia Context Engineering y el Framework Archwise. El objetivo no es poseer "Prompt Engineering" como territorio, sino usarlo como puente hacia territorios propios.
