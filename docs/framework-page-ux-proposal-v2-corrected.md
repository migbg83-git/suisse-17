## PROPUESTA V2: MÉTRICAS

### Opción A: Mantener Énfasis en Arquitectura (RECOMENDADA)

```
· 6 capas arquitectónicas
· Orden causal (no cronológico)
· 30 artículos sobre decisiones críticas
```

**Por qué:**
- ✓ "Capas arquitectónicas" = mantiene precisión
- ✓ "Orden causal" = tesis central (no jerga si se explica)
- ✓ "30 artículos" = concreto (elimina "corpus")

**Riesgo:** "Orden causal" puede ser jerga para PMO

---

### Opción B: Más Accesible (ALTERNATIVA)

```
· 6 capas de decisión arquitectónica
· Secuencia causal de activación
· 30 artículos de arquitectura IA
```

**Por qué:**
- ✓ "Capas de decisión" = más concreto que "capas arquitectónicas"
- ✓ "Secuencia causal" = menos jerga que "orden causal"
- ✓ "Artículos de arquitectura IA" = elimina "corpus"

**Ventaja:** Más accesible manteniendo tesis

---

### Opción C: Hibrida Mínima

```
· 6 capas arquitectónicas
· Conectadas por dependencias (no por fecha)
· 30 artículos que explican cada decisión
```

**Por qué:**
- ✓ "Capas arquitectónicas" = preciso
- ✓ "Dependencias (no por fecha)" = explica el concepto sin jerga
- ✓ Muy claro

**Recomendación:** OPCIÓN B (balance accesibilidad + precisión)

## PROPUESTA V2: BLOQUE 1 - "¿Qué es el Framework Archwise?"

**Ubicación:** Después del hero

**Contenido (100 palabras):**

```
¿Qué es el Framework Archwise?

Es un framework arquitectónico para construir capacidades IA empresariales 
respetando dependencias reales entre decisiones. Reconoce que ganar escala 
no es agregar tecnología, sino resolver 6 capas de problemas en orden:
diagnóstico, contexto, gobernanza, operación, memoria y autonomía.

Cada capa debe completarse antes de la siguiente. Cada artículo en Archwise
explica una decisión crítica: qué riesgo mitiga, cómo conecta con otras 
capas, y cuándo activarla según tu contexto.

Tu rol (CTO, arquitecto, líder) y dónde está tu organización hoy 
determinan tu punto de entrada.
```

**Conta:** 108 palabras ✓

**Responde:**
- ✓ ¿Qué es Archwise? = Framework arquitectónico (no modelo de madurez)
- ✓ ¿Por qué 6 capas? = Problemas en orden causal
- ✓ ¿Qué encontraré? = Decisiones críticas y cuándo activarlas
- ✓ ¿Dónde empiezo? = Tu rol + contexto determinan entrada

## PROPUESTA V2: BLOQUE 2 - "Cómo navegar Archwise"

**Ubicación:** Después de Bloque 1

**Contenido (85 palabras):**

```
Cómo navegar Archwise

No por orden de publicación, sino por dependencias arquitectónicas. 
Cada decisión que finalizas en una capa habilita las decisiones 
de la siguiente. Si salteas pasos, generas deuda arquitectónica.

Usa las rutas recomendadas si no tienes claridad: te guían en orden 
lógico según tu rol. O explora el mapa para entender cómo cada artículo 
conecta con los otros y qué capa resuelve.

El orden importa. No es flexibilidad; es causalidad.
```

**Conteo:** 83 palabras ✓

**Responde:**
- ✓ ¿Por qué no por fecha? = Dependencias arquitectónicas (no cronología)
- ✓ ¿Qué pasa si salto? = Deuda arquitectónica
- ✓ ¿Cómo navego? = Rutas recomendadas + Mapa
- ✓ ¿Por qué importa el orden? = Causalidad (no flexibilidad)
