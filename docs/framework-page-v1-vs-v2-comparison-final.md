# V1 vs V2: Side-by-Side Comparison
## Por qué V2 es fiel a Archwise y V1 no

**Fecha:** 9 de junio de 2026 | **Decisión:** V2 es la propuesta correcta

---

## EL ERROR FUNDAMENTAL DE V1

V1 decía: **"6 niveles de madurez IA"**

Eso falsifica a Archwise como:
- Un modelo progresivo (tipo CMM: Inicial → Repetible → Definido → Gestionado → Optimizado)
- Una escalera de madurez donde cada escalón es "más maduro"

**Realidad de Archwise:**
- Es un framework arquitectónico con 6 capas de problemas decisionales
- Las capas tienen **dependencias causales**, no progresión de madurez
- Si estás en Layer-2, podrías no ser "inmaduro"; solo estás resolviendo contexto
- Es como decir "un edificio tiene 6 pisos" => no significa que subir pisos = "más maduro"

## COMPARACIÓN: BLOQUE "¿QUÉ ES ARCHWISE?"

### V1 (RECHAZADA):

```
"Es una hoja de ruta para escalar IA sin deuda técnica o gobernanza. 
Estructura 6 niveles de implementación: diagnóstico, contexto, gobernanza, 
operación, memoria y autonomía.

Cada nivel resuelve un riesgo específico; cada artículo explica una 
decisión crítica. Tu rol (CTO, arquitecto, líder, consultor) y objetivo 
(diagnosticar, diseñar, operar, medir, mejorar) determinan por dónde empezar."
```

❌ **"6 niveles de implementación"** = De nuevo, suena a progresión  
❌ **"Cada nivel resuelve un riesgo"** = Ignora que algunos riesgos pueden ser paralelos  
❌ No dice "framework arquitectónico"

---

### V2 (PROPUESTA):

```
"Es un framework arquitectónico para construir capacidades IA empresariales 
respetando dependencias reales entre decisiones. Reconoce que ganar escala 
no es agregar tecnología, sino resolver 6 capas de problemas en orden:
diagnóstico, contexto, gobernanza, operación, memoria y autonomía.

Cada capa debe completarse antes de la siguiente. Cada artículo explica 
una decisión crítica: qué riesgo mitiga, cómo conecta con otras capas, 
y cuándo activarla según tu contexto.

Tu rol (CTO, arquitecto, líder) y dónde está tu organización hoy 
determinan tu punto de entrada."
```

✓ **"Framework arquitectónico"** = Posicionamiento directo  
✓ **"Capas de problemas en orden"** = Explica causalidad  
✓ **"Cada capa debe completarse antes de la siguiente"** = Explica dependencia sin jerga  
✓ **"Cómo conecta con otras capas"** = Refuerza arquitectura  
✓ **"Tu rol y dónde está tu organización determinan entrada"** = NO es un camino único

**Ganancia:** Cada frase refuerza que es arquitectónico, no madurez
