# Sitemap Fix Report - Article 27

## Root Cause
- `sitemap.xml` is generated by `scripts/generate-seo-files.ts` from `src/assets/content/articles.json` and written into `public/sitemap.xml`.
- The standard build command in `sites/enterprise-ai/archwise/package.json` previously ran only:
  - `build:content`
  - `ng build`
- Because `build:seo` was not executed in `build`, `public/sitemap.xml` could remain stale and then be copied to `dist` unchanged.
- Result: article 27 existed in content/prerender/canonical, but sitemap in build output did not include it.

## Files Modified
- `sites/enterprise-ai/archwise/package.json`
  - Updated `build` script from:
    - `npm run build:content && ng build`
  - To:
    - `npm run build:content && npm run build:seo && ng build`
